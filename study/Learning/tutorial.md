## 01 先建立一个可信的学习问题（已展开）

目标：能定义输入、输出、损失与评价指标，并解释为什么训练效果好不等于学会。

前置：向量、均值、条件概率；会读 Python 数组。

主链：样本与标签 → 划分数据 → 学习参数 → 验证选型 → 一次性测试

### 学习到底在调整什么？

监督学习给定样本 (x, y)，用带参数的函数 fθ(x) 预测 y。训练调整 θ 来降低训练集上的平均损失；模型结构、学习率、正则化强度等超参数通常通过验证集选择。分类输出可以是类别概率，回归输出是连续数值。无监督学习没有同样的类别标签；自监督学习从数据自身构造监督信号。

### 训练、验证与测试各有一个职责

训练集用于更新参数，验证集用于模型选择和早停，测试集用于最终估计泛化。标准化的均值与方差也只能从训练集拟合。若反复看测试表现来调参，测试集事实上就成了验证集。时间序列应尊重时间顺序；同一个人的近重复样本不宜随机落入不同集合。

### 把容量与数据量放在一起看

欠拟合常表现为训练和验证误差都高；过拟合常表现为训练误差低、验证误差高。增加容量可能改善欠拟合，也可能扩大泛化差距。验证曲线是诊断线索，不能仅凭两条曲线断言唯一原因；还要排查分布差异、标签错误和数据泄漏。

### 损失与指标不是同一个东西

可微的交叉熵便于优化；accuracy、precision、recall、F1 等回答不同业务问题。1% 阳性的数据上全预测阴性可得 99% accuracy，却一个阳性也找不到。确定正类、阈值和误判代价后再选指标。多分类宏平均与微平均也不能混用。

公式：

```text
J(θ) = (1/N) Σᵢ ℓ(fθ(xᵢ), yᵢ) + λR(θ)
precision = TP / (TP + FP)
recall = TP / (TP + FN)
F1 = 2PR / (P + R)
```

例子：100 个样本中有 10 个正类。模型预测 8 个正类，其中 6 个正确：TP=6、FP=2、FN=4、TN=88。accuracy=94%，precision=75%，recall=60%，F1≈66.7%。这四个数共同描述了同一个模型，不能相互替代。

误区：先对全部数据做标准化、再拆分训练与测试，会泄漏测试分布信息。把数据增强后的同源图片随机分到不同集合也有类似问题。

## 02 把一次训练拆成六个动作（已展开）

目标：能解释张量形状、自动微分与训练循环，写出一次完整参数更新。

前置：第 01 课；矩阵乘法与导数。

主链：取一个 batch → 前向计算 → 标量损失 → 清空旧梯度 → 反向传播 → 更新参数

### 先写形状，再写模型

使用行样本约定：输入 X 是 [B,D]，线性层权重按数学写法 W 是 [D,H]，输出 XW+b 是 [B,H]。PyTorch 的 nn.Linear(D,H) 内部 weight 则是 [H,D]，执行 X·weightᵀ+b。看到转置先核对约定，不要机械搬公式。

### 自动微分记录的是运算关系

前向运算构成计算图。对标量 loss 调用 backward()，按链式法则把梯度累加到叶子参数的 .grad。它不负责更新参数；optimizer.step() 才做更新。Python 数字化或 detach 会切断对应路径，不能在需要梯度的中间值上随意使用。

### 为什么要清空梯度？

默认反向会累加梯度。普通训练通常每个 batch 在 backward 前清零；梯度累积训练则有意累加多个 batch 后再更新，并正确缩放损失。清零与累积各有用途，问题在于是否符合你的设计。

### 训练模式与梯度开关是两条轴

model.eval() 改变 Dropout 和 BatchNorm 等模块的行为，不自动关闭梯度。torch.no_grad() 关闭梯度记录，不自动切换模型模式。验证通常两者都用。恢复训练后要调用 model.train()。不要把验证样本送入训练模式的 BatchNorm 来更新统计量。

公式：

```text
X: [B,D] → Linear(D,H) → [B,H] → ReLU → Linear(H,C) → [B,C]
loss = CrossEntropyLoss(logits, labels)  # labels: [B], 整数类别
θₜ₊₁ = θₜ − η · ∇θ loss
```

例子：B=32、D=20、H=8、C=3 时，第一层参数为 20×8+8=168，第二层为 8×3+3=27，总共 195。batch 从 32 改成 64 不会改变参数量。分类 logits 是 [32,3]，标签是 [32]，通常为 torch.long。

误区：CrossEntropyLoss 接收未归一化的 logits。先 softmax 再送入它会改变实际计算，通常不是你想优化的目标。

2. 把 batch 形状和每层参数形状打印出来；确认与纸上计算一致。
3. 在复制的实验中故意去掉 zero_grad，对比参数梯度和 loss 曲线；恢复后写明梯度累加发生在哪里。

## 03 从 MLP 推出反向传播（已展开）

目标：能从损失沿计算图推导两层网络梯度，并用数值差分验证。

前置：第 02 课；链式法则、逐元素乘法。

主链：线性变换 → 非线性激活 → 输出 logits → softmax + CE → 误差信号反传 → 共享分支梯度求和

### 非线性为什么必要？

没有激活函数，多层线性变换仍等价于一个线性变换。ReLU、sigmoid、tanh 引入非线性，使网络能够表达弯曲决策边界。sigmoid 在大正值或负值附近导数很小；ReLU 正区间导数为 1，但负区间可能长期不更新。不能无条件断言 ReLU 一定学得更快。

### 从概率到交叉熵

softmax 把 logits 转成类别概率。对正确类的负对数概率做损失，就是单样本负对数似然；独立样本的似然相乘，取对数后变成求和。平均损失和总负对数似然差一个常数因子。减去最大 logit 再求指数可改善数值稳定性。

### 关键简化：输出梯度等于 p−y

softmax 的类别互相耦合，而交叉熵与它组合后，单样本对 logits 的梯度简化成 p−y。该式假定 y 是和为 1 的目标分布，且未再加样本权重等项。batch 平均时别忘除以 B。然后按线性层和激活层的局部导数向前一层传。

### 共享参数只计一份，梯度收两路

Siamese 两个分支共用 W,b，参数量不会因为执行两次而翻倍。总梯度是来自两条路径的贡献相加，再加正则项梯度。相同输入不等于参数共享；伪 Siamese 若 W₁、W₂ 独立，就分别更新。

公式：

```text
行样本约定：A₁=XW₁+b₁，H=σ(A₁)，Z=HW₂+b₂
P=softmax(Z)，L=−(1/B)ΣᵢΣ꜀ Yᵢ꜀ log Pᵢ꜀
δ₂=(P−Y)/B；∂L/∂W₂=Hᵀδ₂
δ₁=(δ₂W₂ᵀ) ⊙ σ′(A₁)；∂L/∂W₁=Xᵀδ₁
∂L/∂b = 沿 batch 维求和
```

例子：三分类 logits=[0,0,0]，正确类别为第 2 类。概率为 [1/3,1/3,1/3]，损失 ln3≈1.099，对 logits 的梯度是 [1/3,−2/3,1/3]。梯度下降让正确类 logit 增大、其他类减小。

误区：不要把局部导数 σ′(A) 漏掉；也不要给已除以 B 的梯度再除一次。做数值梯度检查时避开 ReLU 的不可导点 0。

## 04 让卷积看懂局部结构（已展开）

目标：能计算卷积输出形状、参数量和感受野，并解释参数共享。

前置：第 03 课；张量的 batch/channel/height/width。

主链：NCHW 图像 → 局部滑窗 → 跨通道求和 → 生成特征图 → 激活与下采样 → 分类头

### 卷积在共享什么？

一个输出通道对应一组覆盖所有输入通道的卷积核。这组权重在空间位置复用，提取某种局部模式。深度学习库通常实现互相关，即不翻转卷积核；课程语境常统一称卷积。卷积的平移等变性不等于分类结果自动平移不变，边界与步幅也会影响它。

### 输出大小来自窗口放得下多少次

padding 扩展边界，stride 控制相邻窗口间距，dilation 控制核采样点间距。先算有效核宽 d(k−1)+1，再计算合法窗口数量。H 和 W 分别算；输入太小或参数不合法时应明确报错，而不是给负维度。

### 参数量与图片面积无关

标准卷积参数量为 C_out×(C_in×k_h×k_w+1)，其中 +1 是每个输出通道的偏置。特征图的 H×W 决定计算和激活内存，但不直接改变该层参数量。分组卷积、深度可分离卷积的公式不同。

### 堆叠小核与逐步扩大视野

两个 stride=1 的 3×3 卷积，理论感受野达到 5×5，同时插入了额外非线性。池化降低空间分辨率，带来信息损失。感受野描述可能影响输出的位置范围，不代表所有位置的实际影响一样大。

公式：

```text
H_out = ⌊(H + 2p − d(k−1) − 1)/s⌋ + 1
标准卷积参数 = C_out × (C_in × k² + 1)  # 有 bias
感受野 rₗ = rₗ₋₁ + (kₗ−1)dₗjₗ₋₁
采样间距 jₗ = jₗ₋₁sₗ，初始 r₀=j₀=1
```

例子：输入 [32,3,32,32]，Conv2d(3,16,kernel_size=3,padding=1,stride=1) 输出 [32,16,32,32]，参数 16×(3×9+1)=448。再做 2×2、stride=2 池化，得到 [32,16,16,16]。

误区：把输入通道数当成核数量，或漏掉跨通道求和，都会算错参数量。池化通常没有可学习参数，但会改变形状与感受野。

## 05 理解深层网络为什么能训练（已展开）

目标：能解释残差连接、归一化和正则化各自解决的问题。

前置：第 04 课；梯度的链式传播。

主链：特征提取块 → 归一化与激活 → 残差相加 → 更深的表示 → 全局池化 → 分类

### 从架构名称退回设计问题

AlexNet 展示更深 CNN 的能力；VGG 用规则堆叠的小卷积核；Inception 在分支间组合多尺度特征；ResNet 加入残差路径。学习时不要只背层数，要能比较计算、参数、信息流和优化难度。

### 残差路径给梯度一条直接路线

残差块 y=x+F(x) 的梯度包含恒等项 I。网络可以在恒等映射上学习修正，从而缓解某些深度优化问题。但残差不保证不会过拟合，也不保证任意网络都稳定。输入输出形状不一致时，需要投影或相应的维度处理后才能相加。

### BatchNorm 依赖训练与推理状态

BatchNorm 按其规范化轴计算均值方差，再用可学习缩放和平移恢复表达能力。训练通常用 batch 统计并更新运行统计；评估通常用运行统计。小 batch、分布变化或错误模式切换会影响结果。它不是简单地让所有层输出永远标准正态。

### Dropout 是训练期扰动

倒置 Dropout 训练时随机保留激活并按 1/(1−p) 缩放，使期望保持；评估时不再随机丢弃。权重衰减直接约束参数；数据增强约束对变换的鲁棒性。这些机制不能当作互相完全等价的开关。

公式：

```text
残差：y = x + F(x)
∂y/∂x = I + ∂F/∂x
BatchNorm：x̂ = (x−μ)/√(σ²+ε)，y = γx̂+β
倒置 Dropout：训练 y = m⊙x/(1−p)，m~Bernoulli(1−p)
```

例子：残差主分支输出 [B,64,16,16]，旁路仍是 [B,32,32,32]，不能直接相加。可以用 1×1、stride=2 的投影卷积把旁路变为 [B,64,16,16]。此投影会增加参数，不再是纯恒等映射。

误区：Dropout(p=0.5) 不是每次精确删除一半神经元；它通常逐元素随机采样。评估时误用 train 模式会使预测不稳定。

实践阅读与验证顺序：

3. 在同一个小模型上分别启用 Dropout 和权重衰减，保留控制变量记录；不要把单次结果当成普遍结论。

## 06 用曲线诊断优化问题（已展开）

目标：能解释学习率、动量和自适应步长，制定可验证的训练诊断顺序。

前置：第 03 课；梯度与指数滑动平均。

主链：计算 batch 梯度 → 更新一阶/二阶统计 → 决定更新幅度 → 监控训练与验证 → 调整计划

### 学习率决定走多远

梯度给出局部最陡上升方向，负梯度是下降方向，但有限步长不保证损失下降。二次函数上可以精确看到稳定区间；真实深网更复杂。学习率过小可能进展缓慢，过大可能震荡或发散。batch 变化也会改变梯度噪声。

### 动量让方向具有记忆

动量平滑历史梯度，可减少某些来回摆动，在方向一致处积累速度。不同实现对动量系数与学习率的写法可能不同，比较公式时先统一约定。动量不是简单把所有梯度放大同一个倍数。

### Adam 维护两个统计量

一阶矩估计方向，二阶原始矩估计梯度平方尺度；偏置修正补偿零初始化带来的早期偏差。固定一阶矩时，分母越大更新越小，但实际更新由分子、分母和学习率共同决定。Adam 不保证比 SGD 泛化更好。

### 先验证能学，再追求更好

先在几十个样本上过拟合，排查形状、标签、loss 与梯度；再检查数据划分、训练/验证模式、归一化与学习率。记录种子和指标，改变一个主要变量。NaN 时从输入、loss、梯度范数、参数范围逐段定位。

公式：

```text
gₜ = ∇θ L_batch
mₜ=β₁mₜ₋₁+(1−β₁)gₜ；vₜ=β₂vₜ₋₁+(1−β₂)gₜ²
m̂ₜ=mₜ/(1−β₁ᵗ)；v̂ₜ=vₜ/(1−β₂ᵗ)
θₜ₊₁=θₜ−η m̂ₜ/(√v̂ₜ+ε)
L(w)=½aw² 时，GD 稳定条件：0<ηa<2
```

例子：L(w)=½×2w²，w₀=3。η=0.1 时 w₁=2.4；η=0.75 时 w₁=−1.5，符号翻转但绝对值缩小；η=1.1 时 w₁=−3.6，开始发散。可见“跨过最优点”与“发散”不是同一回事。

误区：不能只比较最后一个 epoch 的训练 loss 来选择优化器。检查验证表现、计算预算、超参数搜索公平性和多次运行波动。

## 07 沿时间展开 RNN（已展开）

目标：能把序列计算展开成共享参数的图，解释 BPTT、梯度消失与 LSTM 门控。

前置：第 03、06 课；理解共享参数梯度相加。

主链：token/特征输入 → 更新隐藏状态 → 逐时刻输出 → 累计序列损失 → 沿时间反传 → 生成时反馈预测

### 状态把历史压缩到当前

普通 RNN 在每个时刻读入 xₜ 与 hₜ₋₁，产生 hₜ；各时刻共用同一组参数。状态让过去影响现在，但固定维度的状态并不能无损保存任意长历史。输入序列、输出序列与 mask 的长度必须核对。

### BPTT 是在展开图上做反传

未来损失会沿隐藏状态链影响早期参数。对共享 W_hh 的梯度，要把各时间步贡献累加。只算当前输出到当前隐藏状态会漏掉未来路径。截断 BPTT 用分段计算降低内存与传播长度，但会丢掉跨截断边界的梯度。

### 长链乘积为何容易出问题

梯度包含多次 Jacobian 相乘，尺度可能指数衰减或增长。tanh 饱和会进一步压小导数。梯度裁剪主要限制梯度爆炸，不能直接补回消失的梯度；初始化、结构与门控也很重要。

### LSTM 给记忆一条可控通路

遗忘门控制保留旧 cell state，输入门控制加入新信息，输出门控制暴露多少记忆。cell state 的加法路径有助于长程传播，但并不保证无限记忆。训练时 teacher forcing 使用真实前一 token，生成时通常使用模型自己的输出，二者可能产生分布差异。

公式：

```text
hₜ=tanh(xₜW_xh+hₜ₋₁W_hh+b)
L=Σₜ Lₜ；∂L/∂W_hh=Σₜ hₜ₋₁ᵀδₜ
cₜ=fₜ⊙cₜ₋₁+iₜ⊙gₜ
hₜ=oₜ⊙tanh(cₜ)
此处行样本约定；δₜ 已包含未来时间步传回的贡献。
```

例子：若每一步的简化标量导数都是 0.5，跨 20 步的乘积约 9.54×10⁻⁷；若都是 1.5，则约 3325。这只是说明乘积效应的玩具例子，真实 RNN 的 Jacobian 是矩阵且随输入变化。

误区：同一个模型的不同独立序列间，不应无意复用未清理的隐藏状态。padding token 也不应当作真实监督位置参与损失。

## 08 用 Attention 做内容检索（已展开）

目标：能手算一个注意力行，核对 Q/K/V 维度，解释 mask 与位置编码。

前置：第 03 课 softmax；第 07 课序列任务。

主链：token embedding + 位置 → 投影 Q/K/V → 相似度与 mask → 逐行 softmax → 加权聚合 V → 残差/归一化/FFN

### Q 问问题，K 负责匹配，V 提供内容

对每个 query，把它与所有 key 比较产生分数，再用 softmax 变成权重，对 value 加权求和。Q、K、V 可以来自同一序列的不同投影（self-attention），也可以让 query 与 key/value 来自不同来源（cross-attention）。它们不是必须相等的三个副本。

### 每一行对应一个 query 的选择

Q 为 [B,Tq,dₖ]，K 为 [B,Tk,dₖ]，QKᵀ 为 [B,Tq,Tk]；softmax 沿 key 维。乘 V 后输出 [B,Tq,dᵥ]。除以 √dₖ 有助于控制点积随维度增长的尺度，避免 softmax 过早饱和。

### Mask 决定可访问的信息

因果 mask 阻止当前位置读取未来 token，padding mask 阻止读取补齐位置。通常在 softmax 前把禁止位置设为负无穷或足够小的值。把全行都屏蔽会产生无有效注意力的问题，必须由输入和 mask 设计避免。

### Transformer 还需要哪些部件？

多头注意力在多个投影子空间聚合信息，再拼接和投影。逐 token FFN 提供非线性变换，位置编码注入顺序，残差和 LayerNorm 支持优化。没有位置信息且没有位置相关 mask 时，自注意力具有置换等变性，无法独自区分序列次序。

公式：

```text
Attention(Q,K,V)=softmax(QKᵀ/√dₖ + M)V
Q:[B,Tq,dₖ]，K:[B,Tk,dₖ]，V:[B,Tk,dᵥ]
权重:[B,Tq,Tk]；输出:[B,Tq,dᵥ]
标准密集自注意力的分数矩阵大小随 T² 增长。
```

例子：一个 query 对三个 key 的已缩放分数为 [1,0,−1]，softmax≈[0.665,0.245,0.090]。若 values=[10,20,30]，输出≈14.25。屏蔽第三个 key 后要对剩下两个重新归一化，结果不等于把原输出简单减掉第三项。

误区：softmax 轴错了也可能不报 shape 错误，但含义已经错了。注意力权重较大不自动等价于可靠的因果解释。

## 09 把图像变成 token 序列（已展开）

目标：能计算 patch 数和注意力开销，比较 CNN、ViT 与窗口注意力。

前置：第 04、08 课。

主链：切分不重叠 patch → 展平并线性投影 → 加入位置/类别 token → Transformer blocks → 汇聚 → 分类

### 一个 patch 就是一份局部输入

将 H×W 图像切为 P×P 的非重叠块，块数为 HW/P²（这里假设整除且无额外 padding）。RGB 块展平长度是 3P²，再投影到 d 维。patch embedding 也可用核与步幅均为 P 的卷积实现。

### 类别 token 是汇聚方式之一

经典 ViT 使用可学习 class token，经过多个 block 与图像 token 交互后供分类头读取；也可以采用全局平均等其他汇聚方式。位置编码帮助区分同一视觉内容出现在不同位置。

### patch 越小，序列越长

减小 patch 尺寸保留更细的空间信息，但 token 数和密集注意力开销增长。只看模型参数量会漏掉激活内存的变化。图像分辨率变化还涉及位置编码适配和训练设置。

### 局部先验与全局交互的取舍

CNN 通过局部连接和权重共享引入空间先验；标准 ViT 可直接进行全局 token 交互，数据和训练配方很重要。Swin 等层级窗口方法限制局部注意力，再通过移动窗口及层级结构传播信息。不能把“Transformer”简单等同于更高准确率。

公式：

```text
N = (H/P) × (W/P)
patch 展平维度 = C×P²
含 class token 时 T=N+1
密集注意力每个 head 的分数矩阵 = T×T
```

例子：224×224 RGB 图像，P=16 时 N=14×14=196，含 class token 为 197。P=8 时 N=784，含 class token 为 785；分数矩阵元素比为 785²/197²≈15.9，而不是仅增加 4 倍。

误区：patch embedding 的权重在各 patch 位置共享，因此投影层参数量不随 patch 数直接线性增长。

## 10 理解 GAN 的两方博弈（已展开）

目标：能分别写出判别器和生成器的一次更新，识别训练不稳定与模式崩溃。

前置：第 02、03、06 课；二分类损失。

主链：采样噪声 → 生成假样本 → 更新判别器 → 重新生成/评分 → 更新生成器 → 观察质量与多样性

### 两张网络优化不同目标

生成器 G 把噪声 z 映射成样本，判别器 D 区分真与假。更新 D 时，假样本应与 G 的梯度图断开；更新 G 时，需要通过 D 对输入的梯度传回 G，但不需要更新 D 的参数。断开错了路径会让生成器完全收不到信号。

### 生成器损失有常见变体

原始 minimax 中 G 最小化 log(1−D(G(z)))，在某些阶段梯度弱。常用 non-saturating 损失改为 −log D(G(z))，希望假样本被判真。它与原始博弈目标有关联，但不是完全相同的数值表达式。

### 低 loss 不等于样本好

GAN 训练是动态博弈，两个 loss 会互相影响。模式崩溃指生成器只覆盖少量模式，即使样本看似逼真也缺少多样性。用固定噪声看训练过程，同时用新噪声看覆盖范围；不能只挑最好看的几张。

### WGAN 改变的是距离与约束

WGAN 用 critic 的分数差估计 Wasserstein 目标，不把输出直接当真假概率，并需要满足 Lipschitz 约束。WGAN-GP 用梯度惩罚近似约束。DCGAN 是卷积架构设计；LSGAN 则改变对抗损失，二者属于不同维度的选择。

公式：

```text
L_D = −Eₓ log D(x) − E_z log(1−D(G(z)))
常用 non-saturating：L_G = −E_z log D(G(z))
更新 D：fake = G(z).detach()
更新 G：fake = G(z)，梯度经过 D(fake) 回到 G
实际使用 logits 时可用稳定的 BCEWithLogitsLoss。
```

例子：若 D(fake)=0.01，non-saturating 生成器损失为 −ln0.01≈4.605；若变为 0.5，则约 0.693。下降说明当前 D 更难识别该批假样本，但还不能证明覆盖了真实分布的所有模式。

误区：生成器更新时对 fake 使用 detach，会切断从 D 回到 G 的梯度。忘记分开两个优化器的梯度清零也会污染更新。

## 11 从加噪走到生成（已展开）

目标：能区分前向加噪、训练噪声预测器和反向采样，理解条件控制。

前置：第 02、06、10 课；高斯噪声、均方误差。

主链：干净样本 x₀ → 随机时间步 t → 构造带噪 xₜ → 预测噪声 → MSE 更新网络 → 从噪声逐步采样

### 前向过程是已知的扰动机制

给定噪声日程 βₜ，逐步把数据混入高斯噪声。用累计乘积 ᾱₜ 可以直接从 x₀ 构造任意时间步 xₜ，不必从 1 一步步模拟。模型接收时间步，因为不同噪声水平对应不同去噪难度。

### 训练目标与采样过程不同

常见 ε-parameterization 训练模型预测加入的噪声，用均方误差监督。一次训练只需随机抽一个 t；生成时从随机噪声出发，按选定采样器反复调用网络。预测噪声不是简单把噪声图输出后“自动得到照片”，还需要反向更新公式。

### 一个样本的噪声不代表一条完整轨迹

把同一个固定 ε 代入不同 ᾱₜ，可以直观看边际加噪程度，但不是逐步独立加噪的 Markov 轨迹。互动示意使用这种耦合方式，方便观察信号强度；它没有加载或训练去噪模型。

### 潜空间与条件控制降低或改变成本

Latent diffusion 先用编码器压缩图像，在潜空间做扩散，再解码。条件可通过 cross-attention 等方式进入网络。Classifier-free guidance 组合无条件与有条件预测，强度过高可能损害多样性或产生伪影；ControlNet、LoRA、DreamBooth 是不同的控制或适配思路。

公式：

```text
αₜ=1−βₜ；ᾱₜ=∏ₛ₌₁ᵗ αₛ
xₜ=√ᾱₜ x₀ + √(1−ᾱₜ) ε，ε~N(0,I)
L_simple=E[‖ε−εθ(xₜ,t,c)‖²]
常见 CFG 约定：ε_guided=ε_uncond+s(ε_cond−ε_uncond)
此约定中 s=0 为无条件，s=1 为条件预测。
```

例子：ᾱₜ=0.81 时，信号系数是 0.9，噪声系数 √0.19≈0.436。它们不是直接相加等于 1 的混合权重；在信号与噪声独立且单位方差时，两项方差之和为 1。

误区：训练只随机抽一个时间步，不代表生成只需一步。生成步数、采样器与模型训练目标应配套，不能随意套反向公式。

## 12 从识别类别到定位对象（已展开）

目标：能计算 IoU，解释 NMS、AP 和检测器的分类/定位分工。

前置：第 01、04、08 课。

主链：图像特征 → 产生候选框 → 类别与坐标预测 → 置信度筛选 → NMS/集合预测 → 匹配并评价

### 一个预测同时包含“是什么”和“在哪里”

检测输出不固定数量的对象类别、边界框与分数。训练要建立预测和真值间的分配关系，再计算分类和定位损失。两阶段方法先产生候选再精细识别；单阶段方法密集预测。实际速度与精度取决于具体实现和设置。

### IoU 是几何重叠，不是概率

框 A、B 的交并比为交集面积除以并集面积。相交宽高必须截断为非负。坐标 convention 要统一：连续坐标的面积不能随意加 1。IoU 对小框的坐标误差尤其敏感。

### NMS 解决重复预测

标准贪心 NMS 先保留高分框，再抑制与它 IoU 超阈值的同类候选。阈值更低通常更容易抑制重叠框，可能误伤拥挤场景的不同对象。不同变体可能跨类或按类处理，说明实现约定很重要。

### AP 不等于某个阈值上的 accuracy

按分数排序，基于指定 IoU 阈值和匹配规则标记 TP/FP，形成 precision–recall 曲线并计算 AP。mAP 再对类别或多个 IoU 阈值求平均，必须说明协议。重复检测同一真值不能都算 TP。DETR 用集合预测与匹配设计，不能把标准 NMS 流程套到所有检测器。

公式：

```text
IoU(A,B)=area(A∩B)/[area(A)+area(B)−area(A∩B)]
交集宽=max(0,min(x₂ᴬ,x₂ᴮ)−max(x₁ᴬ,x₁ᴮ))
交集高同理；连续坐标约定，不额外 +1
AP：在明确匹配及插值协议下对 PR 曲线汇总。
```

例子：A=[0,0,2,2]，B=[1,1,3,3]。两框面积均为 4，交集面积为 1，并集为 7，所以 IoU=1/7≈0.143。它不是两个框面积比，也不是交集除以其中一个框。

误区：不要把置信度阈值、NMS IoU 阈值和评价匹配 IoU 阈值当作同一个参数。它们作用在不同阶段。

## 13 给每个像素一个判断（已展开）

目标：能区分语义/实例分割，解释上采样、跳连和分割评价。

前置：第 04、05、12 课。

主链：编码空间特征 → 融合不同尺度 → 恢复分辨率 → 输出像素 logits → 生成 mask → 按类计算指标

### 语义与实例回答不同问题

语义分割给每个像素分配类别；实例分割进一步区分同类的不同对象。全景分割结合可数对象与背景区域的统一标注。检测框描述粗定位，分割 mask 描述更精细的形状。

### 编码器压缩，解码器恢复

下采样获得更大感受野但损失空间细节。FCN 用卷积化输出与上采样恢复密集预测；U-Net 类跳连融合浅层高分辨率信息和深层语义。插值、转置卷积与其他上采样方式有不同的参数和伪影风险。

### 空洞卷积扩大采样范围

dilation 在核元素间引入间隔，在不一定降低输出分辨率的条件下扩大理论感受野。它不会因为插入空位而增加同一核的可学习权重数，但采样网格可能带来栅格效应。

### 像素准确率会被背景主导

背景占 95% 的图片，全预测背景也可能获得很高像素准确率。按类 IoU 与 Dice 能更好暴露少数类问题。计算 mIoU 时必须明确忽略标签、缺失类别和背景是否纳入。提示驱动分割还要说明使用的点、框等提示，不能与无提示方法不加说明地比较。

公式：

```text
多类输出 logits：[B,C,H,W]；标签：[B,H,W]
IoU_c = TP_c/(TP_c+FP_c+FN_c)
Dice_c = 2TP_c/(2TP_c+FP_c+FN_c)
在同一非空二值掩码对上：Dice=2IoU/(1+IoU)
```

例子：某类 TP=30、FP=10、FN=20，则 IoU=30/60=0.5，Dice=60/90≈0.667。若这一类很稀少，整体像素 accuracy 仍可能很高，因此必须按类查看。

误区：不要先 argmax 成离散 mask 再送入交叉熵训练；loss 需要 logits 才能对模型输出传播梯度。上采样标签时通常需要保持离散类别语义。

## 14 用梯度理解与改造图像（已展开）

目标：能区分对参数求梯度与对图像求梯度，解释显著性、对抗样本与风格迁移。

前置：第 03、04 课；计算图。

主链：冻结预训练网络 → 设置输入可微 → 定义分数/内容/风格损失 → 对输入反传 → 更新或可视化图像 → 约束并检查

### 同一个反传工具，可以优化不同变量

训练分类器通常对 θ 求梯度；图像可视化和风格迁移可以固定 θ，对输入图像 x 求梯度。冻结网络参数不意味着切断所有输入梯度，若用 no_grad 包住整个前向，就无法完成这类输入优化。

### 显著图描述局部敏感性

对目标类别得分关于输入的梯度，可观察小扰动在哪些位置影响输出。梯度受尺度和局部非线性影响，不能直接当成可靠因果解释。不同类别、预处理和可视化归一化会改变结果。

### 对抗样本需要明确威胁模型

一个简单非定向攻击沿增大分类损失的方向扰动输入，同时约束扰动范数并裁剪合法像素范围。目标攻击的方向与目标损失定义不同。评价必须说明 ε 的尺度、输入是否标准化、攻击次数与是否使用真实标签。

### 风格迁移约束特征统计

内容损失比较特征空间中的结构，风格损失用 Gram 矩阵描述通道相关统计，总变差损失抑制局部不平滑。Gram 统计弱化了空间排列，并不直接复制某幅画的具体布局。不同损失的归一化和权重决定优化平衡。

公式：

```text
显著性：S = |∂s_c(x)/∂x|（常见形式之一）
非定向 FGSM：x_adv = clip(x + ε sign(∇ₓ L(θ,x,y)))
特征 F:[C,HW]，Gram = FFᵀ（归一化约定需说明）
L_total = λ_c L_content + λ_s L_style + λ_tv L_tv
```

例子：特征为 [64,32,32]，展平后 F=[64,1024]，Gram 为 [64,64]，不是 [1024,1024]。它统计不同通道在空间位置上的共同激活，丢失了精确位置排列。

误区：输入经过标准化后，ε=0.01 与原始 [0,1] 像素空间的 ε=0.01 不是同一扰动预算。

## 15 完成一次可复现的深度学习实验（已展开）

目标：把模型、指标与实验设计连成完整证据链，能解释结果及其边界。

前置：完成基础模块，再按项目方向选择后续课程。

主链：明确问题 → 建立朴素基线 → 核验数据与指标 → 训练与记录 → 消融对比 → 分析失败样本 → 复现与报告

### 用可检验的问题开始

先写输入、输出、约束与成功指标。例如“在固定训练预算下，某种增强是否提高验证集 macro-F1”，比“做一个强大的模型”更容易验证。明确数据授权和划分，先建立简单基线，再增加复杂度。

### 控制变量让比较有意义

比较两种模型时，记录数据、预处理、预训练、训练预算、超参数选择过程与硬件。完全相同的超参数不一定公平，但搜索预算与选择规则应透明。对关键结论做多种种子重复，报告均值、波动及样本量。

### 消融连接机制与观察

去掉某组件，看指标和资源开销如何变化；再检查失败样本是否符合假设。一个消融结果不能自动证明所有因果机制，但能排除部分替代解释。不要把测试集变成反复试错工具。

### 可复现不仅是保存权重

保存代码版本、环境、配置、随机种子、数据划分、日志和评价脚本。硬件和算子可能带来非确定性，应注明。报告同时包含负结果和限制；原课程项目材料与 RAFLCC 演示可参考结构，但其中结论需要回到各自证据验证。

公式：

```text
实验记录 = 数据版本 + 划分 + 配置 + 代码版本 + 种子 + 环境
结果 = 主指标 + 波动 + 计算/采样成本 + 失败案例
对比结论只在相应数据、预算、设置与评价协议范围内成立。
```

例子：对比 GAN 与 diffusion：如果 GAN 训练 10 分钟、diffusion 使用大规模预训练模型，两者的输出不能直接证明某架构更优。可以把问题明确改成“在可用资源下，两种方案的质量与部署成本比较”，并公开预训练与预算差异。
